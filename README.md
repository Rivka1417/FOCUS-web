# Focus - Web Games Portal

A web-based platform for concentration and thinking games. The project features a user management system (login/registration), an interactive game lobby, and a main timing and coordination game called "Catching Inspiration".

## Technologies Used
* **HTML5 & CSS3**: Responsive design, structured layout, and clean user interface.
* **Vanilla JavaScript**: Game logic, state management, form validation, and dynamic DOM manipulation.
* **LocalStorage**: Local database management for storing user credentials and tracking personal statistics (wins/losses).
* **Web Audio API**: Integration of real-time sound effects adapted to game events (success, failure, game over).

## Project Structure
* `html/`: Page structures (login, lobby, game, construction).
* `css/`: Logically separated styling files per page.
* `js/`: Game logic, user authentication, and event handling.
* `images/`: Graphical assets, logos, and animations.

## How to Run
1. Clone or download this repository to your local machine.
2. Navigate to the `html` folder and open `login.html` in any modern web browser.
3. Register a new user, log in, and navigate to the game lobby to start playing.

**Note:** The application's user interface and game content are currently in Hebrew.
